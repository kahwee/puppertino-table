Open **Playground** to explore Controls, **Code** to copy a typed recipe, and **Interactions** to replay workflows. Use Theme and Viewport to compare appearance.

The examples use [Phosphor Icons](https://phosphoricons.com/), following [Puppertino’s icon guidance](https://puppertino.com/docs/icons/). Toolbar symbols use regular weight; selected views use fill. Icon slots remain application-owned React nodes.

For typed rows, inferred cells and consumer Storybook files, start with the <a href="./?path=/docs/start-here-typescript--docs" target="_top">TypeScript usage guide</a>.

## Install

<Source language="bash" code={`pnpm add puppertino-table@${packageJson.version} @tanstack/react-table@9.2.8 @codedgar/puppertino@2 react@19.3.0 react-dom@19.3.0`} />

<Source language="tsx" code={`import { TableView, createPuppertinoColumnHelper } from 'puppertino-table';
import '@codedgar/puppertino/colors';
import '@codedgar/puppertino/lists';
import '@codedgar/puppertino/forms';
import 'puppertino-table/style.css';

const helper = createPuppertinoColumnHelper<{ id: string; name: string }>();
const columns = helper.columns([
  helper.accessor('name', { header: 'Name', size: 280, minSize: 160 }),
]);
const files = [{ id: 'brief', name: 'Project brief.pdf' }];

export function Files() {
  return <TableView data={files} columns={columns}
    getRowId={file => file.id} getRowLabel={file => file.name}
    ariaLabel="Files" density="compact" selectable />;
}`} />

## Choose the right ownership

<IntegrationGuide />

Your app owns data, routes, previews and commands. Components own rendering, navigation and gestures.

<details>
<summary>Compatibility and styling</summary>

Omitted density inherits an enclosing `DensityScope` through CSS custom properties. Explicit presets start a new scope; partial metrics override just the supplied values. Scoped table rules require CSS `@scope` support: Chrome/Edge 118+, Safari 17.4+, Firefox 146+.

React and React DOM (`^19.3.0`), TanStack Table and Puppertino are peers. Base UI is a runtime dependency for context menus. Import Puppertino's dark-mode CSS when using `.p-dark-mode`. No React provider is needed for density.

</details>
